Database
This folder contains the SQL implementation of the NomadStay platform.

Files
nomadstay-database.sql
Main MySQL database schema containing tables, relationships, constraints, views, triggers and sample data.

nomadstay_v2_migration.sql
Migration script that extends the original database with additional functionality such as travel planning, activities, destinations and booking costs.

nomadstay-requirement-queries.sql
Collection of SQL queries used to validate project requirements and demonstrate system functionality.
