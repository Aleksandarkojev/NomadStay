Diagrams
This folder contains the database modelling artifacts created during the development of NomadStay.

Development Process
The database design followed this process:

Interviews → User Stories → BDD Scenarios → Individual ER Diagrams → Group ER Diagram → Mermaid ER Diagram → SQL Database Implementation → Reverse-Engineered EER Diagram

Files
Individual ER Diagram
Created from my own requirements analysis, interviews, user stories, and BDD scenarios. This diagram represents my individual domain interpretation before team consolidation.

Group ER Diagram
Created by combining and refining the individual ER diagrams produced by all team members. This became the shared domain model for the project.

Mermaid ER Diagram
A consolidated logical database model based on the agreed domain design and team discussions. This diagram was used as the foundation for the SQL implementation.

MySQL Reverse Engineering Diagram
Generated from the implemented MySQL database using reverse engineering in MySQL Workbench. This diagram represents the physical database structure after implementation.

Purpose
These diagrams document the evolution of the NomadStay data model from requirements analysis to database implementation.
