UI Design
This folder contains high-fidelity interface concepts for NomadStay.

The designs demonstrate how user requirements, database functionality, and business processes could be presented in a complete web application for digital nomads, remote workers, and business travelers.

Design Overview
Design 01 – Homepage & Search
Purpose: Provide accommodation discovery and advanced search capabilities.

Features:

Destination search
Date selection
Guest selection
WiFi filtering
Coworking filtering
Long-term stay options
Design 02 – Search Results
Purpose: Allow users to compare accommodation alternatives.

Features:

Filtering
Sorting
Price comparison
WiFi information
Coworking information
Favorites
Design 03 – Accommodation Details
Purpose: Provide all information required before booking.

Features:

Room types
Facilities
Rules
Reviews
Shared spaces
Maps and nearby locations
Accommodation characteristics
Design 04 – Booking Workflow
Purpose: Guide users through the reservation process.

Features:

Room selection
Guest management
Date selection
Booking summary
Price calculation
Design 05 – Payment Process
Purpose: Complete the booking securely.

Features:

Card payment
Swish
PayPal
Invoice support
Corporate customer information
Booking summary
Design 06 – User Profile Dashboard
Purpose: Allow users to manage their account and travel activity.

Features:

Bookings
Travel plans
Favorites
Reviews
Payment methods
Account settings
Design 07 – Admin Dashboard
Purpose: Provide platform administration capabilities.

Features:

User management
Accommodation management
Booking management
Review moderation
Activity management
Reporting and statistics
Design Process
The UI concepts were developed after requirements gathering, user interviews, user stories, BDD scenarios, data modelling, SQL implementation, and wireframe validation.

The designs illustrate the planned user experience for the future NomadStay web application.
