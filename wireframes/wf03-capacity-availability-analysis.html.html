BDD Scenarios: 1. Fullbokat boende 2. Nästan fullbokat boende 3. Ledigt boende | Intervjuinsikt: Undvik tid på alternativ som saknar kapacitet.
Aktiv SQL Query (Live Console)
HAVING: Alla statusar 
SELECT
    b.boende_id,
    b.namn,
    COUNT(DISTINCT r.rum_id) AS antal_rum,
    COUNT(DISTINCT br.rum_id) AS bokade_rum,
    COUNT(DISTINCT r.rum_id) - COUNT(DISTINCT br.rum_id) AS lediga_rum,
    CASE
        WHEN COUNT(DISTINCT br.rum_id) >= COUNT(DISTINCT r.rum_id) THEN 'fullbokad'
        WHEN COUNT(DISTINCT br.rum_id) >= COUNT(DISTINCT r.rum_id) * 0.8 THEN 'nastan fullbokad'
        ELSE 'ledig'
    END AS bokningsstatus
FROM boende b
JOIN rum r ON r.boende_id = b.boende_id
LEFT JOIN bokning_rum br ON br.rum_id = r.rum_id
GROUP BY b.boende_id, b.namn;

💡 Affärsvärde & Requirement Validation

Denna query ger direkt stöd för NomadStays skallkrav att boenden kan bli fullbokade. Genom att tydliggöra kapacitetsstatus (fullbokad, nastan fullbokad, ledig) minskar vi risken för överbokning och hjälper såväl enskilda resenärer (Mattias) som företagskunder (Arian) att snabbt ta beslut utan att slösa tid på alternativ utan tillräcklig kapacitet.
