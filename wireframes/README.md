SQL Query Wireframes
This folder contains interactive HTML wireframes developed during the NomadStay project.

Unlike traditional wireframes, these prototypes demonstrate the connection between business requirements, database design, SQL implementation, and user interface concepts.

Wireframes
WF01 – Digital Nomad Search
Purpose: Identify accommodations suitable for digital nomads based on WiFi quality, coworking proximity, and cost considerations.

Demonstrates:

Advanced filtering
SQL views
Requirement traceability
Digital nomad business requirements
WF02 – Accommodation Details Inspector
Purpose: Explore detailed accommodation information and visualize how data is assembled from multiple database tables.

Demonstrates:

SQL joins
Entity relationships
Accommodation details
Database structure visualization
WF03 – Capacity and Availability Analysis
Purpose: Analyze room availability, booking capacity, and occupancy information.

Demonstrates:

Capacity management
Availability calculations
Booking analysis
Operational reporting
WF04 – Accommodation Search Results
Purpose: Display accommodation search results and support filtering, comparison, and booking decisions.

Demonstrates:

Search functionality
Filtering logic
Favorites
Booking workflow entry point
Project Value
These wireframes demonstrate how information collected during interviews and requirements gathering was transformed into:

User Stories
BDD Scenarios
Database Design
SQL Queries
Interactive User Interfaces
The goal was to validate that database functionality supported real user needs before full system implementation.
