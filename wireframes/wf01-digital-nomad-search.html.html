                        User Stories (E2S1 - E2S6)
                    

                    

                        

                            E2S1 – WiFi-hastighet
                            Som digital nomad vill jag kunna se ett boendes WiFi-hastighet.
                            
Koppling: v_digital_nomad_boende.wifi_hastighet_mbps

                        

                        

                            E2S2 – Dedikerad Arbetsplats
                            Som digital nomad vill jag kunna se om boendet erbjuder en dedikerad arbetsplats.
                            
Koppling: v_digital_nomad_boende.skrivbord (TINYINT 1/0)

                        

                        

                            E2S3 – Extern Skärm
                            Som digital nomad vill jag kunna se om en extern skärm finns tillgänglig.
                            
Koppling: v_digital_nomad_boende.extern_skarm (TINYINT 1/0)

                        

                        

                            E2S4 – Ergonomisk Stol
                            Som digital nomad vill jag kunna se om boendet erbjuder en ergonomisk kontorsstol.
                            
Koppling: v_digital_nomad_boende.ergonomisk_stol (TINYINT 1/0)

                        

                        

                            E2S5 – Coworking-Avstånd
                            Som digital nomad vill jag kunna se avståndet till närmaste coworking-space.
                            
Koppling: v_digital_nomad_boende.avstand_coworking_meter

                        

                        

                            E2S6 – Tidszon
                            Som digital nomad vill jag kunna se destinationens tidszon.
                            
Koppling: v_digital_nomad_boende.tidszon

                        

                    

                


                
                

                    

                        
                        BDD-Scenarier
                    

                    

                        
1. Hitta arbetsvänligt boende: Givet att jag söker boenden -> När jag filtrerar på hög WiFi-hastighet -> Så ska jag få upp boenden som passar för distansarbete.

                        
2. Hitta coworking nära boendet: Givet att jag söker boenden -> När jag tittar på ett boende -> Så ska jag kunna se avståndet till coworking-space.

                        
3. Jämföra arbetsmöjligheter: Givet flera boenden -> När jag jämför resultaten -> Så ska WiFi, skrivbord och arbetsutrustning visas.

                    

                


                
                

                    

                        
                        Affärsvärde
                    

                    

                        Denna vy hjälper användaren att direkt avgöra om ett boende fungerar för distansarbete, om nödvändig utrustning finns på plats och om coworking finns tillgängligt i närheten. Det stödjer NomadStays huvudmål att underlätta för digitala nomader att kombinera arbete och resande.
